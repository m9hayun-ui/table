# 🍽 식탁 3종 비교

원형 식탁 구매 고민을 위한 제품 비교 페이지입니다.

## 🔗 접속 주소

**https://m9hayun-ui.github.io/table/**

## 📦 비교 제품

| 제품 | 브랜드 | 사이즈 | 상판 소재 | 쿠폰 최저가 |
|---|---|---|---|---|
| 밀키 원형 | 포레홈 | 850mm | 포세린 세라믹 | 151,200원 |
| 스톤 헤리티지 원형 | 포스트모던 | 950mm | MDF + LPM | 234,060원 |
| 루엔나 원형 | 라티에 | 900mm | 포세린 세라믹 12T | 198,550원 |

## 📋 페이지 내용

- 제품별 사진 및 스펙 카드
- 스펙 / 재질 / 가격 항목별 비교 테이블
- 상황별 추천 의견
- 실제 구매 후기 분석 (장단점 정리)

## ⚠️ 참고사항

- 가격은 변동될 수 있으니 구매 전 링크에서 최신 가격을 확인하세요.
- 포스트모던 상판은 세라믹이 아닌 MDF+LPM 소재입니다. 뜨거운 냄비 직접 올리면 안 됩니다.
